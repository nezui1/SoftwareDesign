# Конструирование программного обеспечения

Репозиторий курсового проекта «Разработка web-приложения генерации учебного расписания».

В `reports/` находятся лабораторные работы. В `scheduler_lab/` находится учебное ядро генератора расписания. Проверки запускаются через Gitea Actions при push и pull request. Рабочая ветка лабораторной работы №5 называется `lab5`.
